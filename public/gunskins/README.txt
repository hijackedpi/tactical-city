GUN SKINS
=========

Put skin .glb files in this folder.

Naming (makes it easy to tell what is what):
  gun_skinname.glb
  e.g.  ak47_redserpent.glb   glock18_riptide.glb   awp_wyverncoil.glb

Gun names to use:
  knife, glock18, deagle, mac10, mp5, mp7, ump45, ak47, m4a1, awp

Tip: retexture the gun's CURRENT model in Meshy so the skin is the exact same
shape and size as the base gun. Then it fits in the hands with no adjustments.

When a skin is in here, tell Claude the file name, which gun, and the skin's
display name, and it will be added to the game and the Inventory.
